# 💡 IdeaVault

IdeaVault is a premium, full-stack MERN platform designed for visionaries, innovators, and developers to share, explore, and collaborate on groundbreaking startup concepts. Built with a gorgeous violet-and-amber theme and complete responsiveness, it provides a hub where ideas meet action.

🔗 **Live Website:** [https://ideavault-client-one.vercel.app](https://ideavault-client-one.vercel.app)

---

## ✨ Key Features

*   **🚀 Interactive Startup Idea Board:** Share innovative campaigns with detailed metadata, including category, budget, target audience, problem statements, and proposed solutions.
*   **🔒 Secure JWT-Based Route Protection:** Access private features (like View Details, My Ideas, and Comments) via secure routing. Authentication options include custom email/password sign-up and login, along with a simulated Google Account login picker.
*   **🌓 Responsive Layout & Dark Mode Toggle:** Experience a premium, responsive interface featuring a collapsible mobile hamburger menu and a global toggle for dark/light mode.
*   **💬 Collaborative Comment Sections:** Engage with project creators in real-time. Logged-in users can write, edit, and delete their own comments on any idea page.
*   **📂 Personal Idea & Interaction Dashboards:** Manage your campaigns with native inline modals for adding, updating, and deleting ideas, and track all projects you have commented on in a dedicated Interactions panel.
*   **🔍 Search, Category Filter, and Sorting:** Instantly find relevant projects using the dynamic keyword search bar, category filters, and sorting parameters by creation date and budget.

---

## 🛠️ Technology Stack

*   **Frontend:** React.js, Vite, TailwindCSS (for utility classes), React Router DOM (v6), React Hot Toast
*   **Backend:** Node.js, Express.js, JSON Web Tokens (JWT) for authentication, Bcrypt.js
*   **Database:** MongoDB Atlas (native driver)
*   **Deployment:** Vercel (Client and Server)
